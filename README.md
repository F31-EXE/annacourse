# Курс «Нейросети для дизайнеров интерьера» — сайт и админка

Лендинг курса Анны Самариной и Django-админка для продаж: курс и модули, тарифы, промокоды,
заказы и заявки на бесплатный урок. Дизайн-система описана в [DESIGN.md](DESIGN.md).

## Запуск локально

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

- Сайт: http://127.0.0.1:8000/
- Админка: http://127.0.0.1:8000/admin/

Миграция `0002_seed_course` сама создаёт курс и шесть модулей из презентации. Тарифов нет, пока
их не добавить в админке; без тарифов блок цен на сайте скрыт, а кнопка ведёт в Telegram.

## Что где

| Путь | Что внутри |
|------|------------|
| `courses/models.py` | Курс, модуль, тариф, промокод, заказ, заявка |
| `courses/admin.py` | Админка: выгрузка в CSV, «отметить оплаченными» |
| `courses/views.py` | Лендинг и API: `/api/lead/`, `/api/order/`, `/api/promo/` |
| `templates/landing/index.html` | Шаблон лендинга |
| `static/` | Стили, 3D-кресло (`main.js`), кейсы «было — стало» (`gen.js`), формы (`forms.js`), картинки |

## Как работает продажа сейчас

1. Посетитель выбирает тариф, вводит имя, почту, телефон и, если есть, промокод.
2. Создаётся заказ со статусом «Ожидает оплаты»; цена и скидка фиксируются на момент заказа.
3. Менеджер видит заказ в админке, отправляет ссылку на оплату и отмечает заказ оплаченным.

Онлайн-оплата (например, ЮKassa) и письма покупателю — следующий шаг.

## Боевой режим

Переменные окружения:

| Переменная | Пример |
|------------|--------|
| `DJANGO_DEBUG` | `0` |
| `DJANGO_SECRET_KEY` | длинная случайная строка (без неё сайт не запустится при `DJANGO_DEBUG=0`) |
| `DJANGO_ALLOWED_HOSTS` | `example.ru,www.example.ru` |
| `DJANGO_CSRF_TRUSTED_ORIGINS` | `https://example.ru` |
| `DJANGO_TIME_ZONE` | `Europe/Moscow` |

Статику собрать командой `python manage.py collectstatic` (в папку `staticfiles/`).
