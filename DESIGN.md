# АННА / ИИ-ИНТЕРЬЕР — Style Reference
> Тёмная мастерская дизайнера. Одно дизайнерское кресло парит в тёплой темноте, а ИИ на глазах перебирает для него обивку.

**Theme:** dark
**Продукт:** онлайн-курс «ИИ в дизайне интерьера» от практикующего дизайнера интерьера.
**Основа:** адаптация системы ORYZO (darkroom product editorial) под образовательный продукт для дизайнеров.

## Идея

Сайт строится вокруг одного объекта: **кресла-«облака»**. Это мягкое округлое кресло из пухлых валиков на круглом основании из ореха, коллекционный предмет мебели. Оно показано как музейный экспонат: 3D-форма, тёплый контровой свет справа сверху, вокруг пустота.

Главная метафора курса — **«Одна форма. Сотня вариантов.»** Форму задаёт дизайнер, а нейросеть мгновенно примеряет к ней ткани, свет и настроение. Поэтому объект на сайте не статичен:
- при прокрутке он поворачивается и переезжает между секциями (как подставка ORYZO, которая разворачивается от вида сверху к 3/4);
- при смене секции «перегенерируется»: делает оборот, и на нём появляется новая обивка (букле → бархат → кожа → лён). Ткани по-разному работают со светом: у бархата отлив, у кожи блеск, у букле рельеф петель;
- в интерактивной секции посетитель сам выбирает обивку и видит строку промпта, которую «отправил» ИИ.

Ближе к концу страницы метафору подтверждает реальная работа: **коллаж превращается в рендер** (см. «Collage → Render»).

Голос ИИ на сайте — **строка промпта**. Это короткая строка заглавными со слешем в начале: `/ОБИВКА: БАРХАТ, РЖАВЫЙ · СВЕТ: ЗАКАТ`. Только она и подписи-кредиты окрашены акцентным оранжевым.

## Tokens — Colors

| Name | Value | Token | Role |
|------|-------|-------|------|
| Warm Cream | `#ffedd7` | `--color-cream` | Весь текст, навигация, обводки кнопок, разделитель «до/после». Никогда не чистый белый. |
| Walnut Shadow | `#100904` | `--color-walnut` | Холст страницы. Тёплый почти чёрный, «тёмная мастерская». |
| Bark Brown | `#382416` | `--color-bark` | Единственная залитая поверхность: одна кнопка-CTA на странице и hover строк программы. |
| Cork Border | `#40372e` | `--color-cork` | Пунктирные разделители секций и строк, обводка карточек. |
| Driftwood | `#6c5f51` | `--color-driftwood` | Второстепенные подписи, плейсхолдеры, неактивные состояния. |
| Ember | `#dc5000` | `--color-ember` | Только голос ИИ (строки промптов), номера модулей и кредиты. Никогда не кнопки. |

### Обивки объекта (не UI-токены)
Используются только для 3D-кресла, в интерфейсе не встречаются. Основание кресла всегда из ореха `#5b3a22`.

| Обивка | Цвет | Характер |
|--------|------|----------|
| Букле | `#efe5d6` | рельеф петель, матовая, лёгкий белый отлив |
| Бархат | `#8a3320` | ржавый, сильный тёплый отлив (sheen) |
| Кожа | `#8f4f26` | коньяк, мелкое зерно, лёгкий лак (clearcoat) |
| Лён | `#cdbfa6` | полотняное плетение, утолщения нитей |

## Tokens — Typography

Вместо одного шрифта ORYZO здесь пара «Мода»: три роли, три гарнитуры, все с полной кириллицей (Google Fonts). Так типографика звучит как интерьерный журнал, а не как техносайт.

### Tenor Sans — заголовки
Контрастный гротеск с «модным» рисунком, как в журналах об интерьере и моде. Только заглавные, вес 400 (другого нет), разрядка `.04em`. Используется для h1–h3, вордмарка «АННА», цифр в карточке автора и мини-вордмарка превью.
- **Line height:** 1.0 на display; 1.06 на заголовках 41px, где у Й и Ё надстрочные знаки задевают строку выше.

### Cormorant Garamond Italic — разговорный голос
Курсив антиквы, вес 400. Только для описательного текста смешанным регистром: объяснения в reveal-секциях, описания модулей, текст в блоке генерации и в записи. Звучит как личная подпись автора.

### Manrope — интерфейс
Спокойный гротеск, веса 400/500, заглавные. Навигация, кнопки, метки, строка промпта, счётчики, поле email. Не спорит с заголовками и хорошо читается мелко (10–12px).

### Type Scale

| Role | Font | Size | Weight | Case | Line Height | Token |
|------|------|------|--------|------|-------------|-------|
| micro / label | Manrope | 10px | 500 | UPPER | 1.2 | `--text-micro` |
| nav / button / prompt | Manrope | 12px | 500 | UPPER | 1.2 | `--text-label` |
| subheading / input | Manrope | 18px | 500 | UPPER | 1 | `--text-sub` |
| heading-sm | Tenor Sans | 24px | 400 | UPPER | 1.09 | `--text-h-sm` |
| module description | Cormorant Italic | 20px | 400 | Mixed | 1.3 | — |
| body | Cormorant Italic | 32px (25 / 23 на телефоне) | 400 | Mixed | 1.26 | `--text-body` |
| heading | Tenor Sans | 41px (32 / 28 на телефоне) | 400 | UPPER | 1.06 | `--text-h` |
| display | Tenor Sans | clamp(48px, 5.6vw, 86px) | 400 | UPPER | 1.0 | `--text-display` |

Курсив Cormorant визуально мельче гротеска того же кегля, поэтому body поднят с 29 до 32px.

### Три голоса
1. **Tenor Sans, заглавные** — заявления: заголовки и вордмарк.
2. **Cormorant Italic, смешанный регистр** — единственный разговорный голос: зачем это дизайнеру.
3. **Голос ИИ** — строка промпта: Manrope 12px, UPPER, 500, цвет Ember, всегда начинается с `/`. Появляется посимвольно, как будто печатается.

## Tokens — Spacing & Shapes

Шкала отступов без изменений: 6, 8, 10, 12, 14, 18, 24, 31, 41, 45, 68, 204px. Боковые поля страницы 24px (16px на телефоне), промежуток между элементами 18px, внутренний отступ карточки 24px.

| Element | Radius |
|---------|--------|
| cards / info-card / preview | 12px |
| inputs | 0px |
| filled pill | 36px |
| ghost button / chips материалов | 22.5px |
| круглые кнопки (play) | 9999px |

## Components

### Fixed Top Navigation
Слева вордмарк «АННА» (14px, 500, UPPER). Справа четыре пункта: ИНТРО · ИДЕЯ · ПРОГРАММА · ЗАПИСЬ (12px). Активный пункт подчёркнут 1px пунктиром Driftwood. Фон — градиент от Walnut к прозрачному, чтобы прокручиваемый текст не сталкивался с навигацией. На телефоне остаются ИНТРО и ЗАПИСЬ.

### Vertical Side Label
По правому краю повёрнутый на 90° текст «ИИ-ИНТЕРЬЕР — ПОТОК 01», 10px. Работает как серийный номер экспоната.

### Hero Lockup
Над заголовком tagline 12px: «ОНЛАЙН-КУРС ДЛЯ ДИЗАЙНЕРОВ ИНТЕРЬЕРА». Заголовок display: «ОДНА ФОРМА. / СОТНЯ / ВАРИАНТОВ.» Он прижат к верхнему левому углу, кресло стоит справа.

### Hero Info Card (низ слева)
12px радиус, фон `rgba(255,237,215,.05)`, 1px Cork. Внутри заголовок UPPER 12px «АВТОРСКИЙ КУРС АННЫ — ДИЗАЙНЕРА ИНТЕРЬЕРА С 12-ЛЕТНЕЙ ПРАКТИКОЙ.», пунктирный разделитель и три цифры (лет / проектов / учеников).

### Lesson Preview Card (низ справа)
Аналог video thumbnail из ORYZO: маленькая карточка 12px с мини-вордмарком, круглой кнопкой ▶ с кремовой обводкой и подписью «ПРЕВЬЮ УРОКА · 02:14».

### Prompt Line
`/МАТЕРИАЛ: ТРАВЕРТИН · СВЕТ: ЗАКАТ`, Ember, 12px UPPER. Стоит под объектом и печатается заново при каждой смене обивки.

### Material Chips
Ряд ghost-кнопок 22.5px: БУКЛЕ · БАРХАТ · КОЖА · ЛЁН. У активной кремовая заливка и тёмный текст. Нажатие запускает «перегенерацию» кресла.

### Collage → Render
Секция с реальной работой из курса, ближе к концу страницы. Она перекрывает 3D-слой собственным фоном Walnut; кресло в это время ставится на паузу.
- Слева: метка «РАБОТА ИЗ КУРСА · МОДУЛЬ 02», заголовок 41px, текст 32px, строка промпта (Ember), тонкая шкала прогресса 1px и счётчик шагов «ГЕНЕРАЦИЯ · ШАГ 12 / 30» (10px, Driftwood), ghost-кнопка «СГЕНЕРИРОВАТЬ ЕЩЁ РАЗ».
- Справа: кадр 4:3, радиус 12px, обводка Cork.
- Анимация запускается, когда кадр виден наполовину. Сначала печатается промпт. Затем за ~4,6 с рендер мягко «распускается» поверх коллажа: из нескольких точек растут пятна с размытыми краями, как акварель на бумаге, и одновременно изображение наводится на резкость из лёгкого размытия. Никаких пикселей, шума и ряби: только плавные переходы. Счётчик «ШАГ N / 30» и шкала идут параллельно.
- После генерации кадр превращается в слайдер «до/после»: разделитель Cream, ручка-кружок, метки «ИИ-РЕНДЕР» и «КОЛЛАЖ».
- Изображения: `img/collage.jpg` и `img/render.jpg` одного размера и ракурса.

### Program Rows
Список, а не сетка карточек (никаких карточек в карточках): каждая строка отделена пунктиром Cork. Внутри номер (Ember, 12px), название модуля 24px UPPER и описание 18px mixed. При hover строка заливается Bark.

### Input (Underline Only)
Только нижняя граница 1px Cream, радиус 0, внутри справа текстовая кнопка «ОТПРАВИТЬ →».

### Filled Pill — один на всю страницу
«ЗАПИСАТЬСЯ НА ПОТОК»: Bark, 36px, 14px × 24px. Больше залитых кнопок на сайте нет.

### Solid Sections
Секции с фотографиями (автор, формула промпта, кейсы, видео, тарифы, контакты) имеют собственный фон Walnut и перекрывают 3D-кресло. Пока они закрывают экран больше чем на 92%, 3D-рендер на паузе.

### Author
Фото автора слева (радиус 12px, обрезка по верхнему краю), справа метка «АВТОР КУРСА», заголовок «АННА САМАРИНА.», текст Cormorant Italic и список фактов с пунктирными разделителями: метка Ember («ПРЕМИЯ», «ПРЕССА») + описание.

### Prompt Formula
Шесть шагов промпта списком (номер Ember, название Tenor Sans 18px) и три квадратные концепции справа.

### Cases (Before → After)
Вкладки-chips: КОЛЛАЖ · СКЕТЧ · ЗАМЕНА МАТЕРИАЛА · БЕТОННАЯ КОРОБКА. У каждого кейса своя пара изображений, промпт и метка исходника. Пропорции кадра берутся из изображения-результата. Анимация проявления — см. «Collage → Render».

### Video
Два вертикальных кадра 3:4 и полный промпт Veo 3.1 строкой Ember.

### Tariffs & Order Dialog
Карточки тарифов: обводка Cork, у выделенного тарифа Cream; цена Tenor Sans 41px, старая цена зачёркнута Driftwood; пункты Cormorant Italic. Выделенный тариф получает единственную залитую кнопку. Заказ оформляется в модальном окне: поля underline-only, пересчёт цены с промокодом на лету.

### Contacts
Три колонки: контакты (метка Driftwood 10px + значение), «Я открыта к сотрудничеству» (три пункта Tenor Sans), партнёры. Под Instagram обязательна сноска о Meta.

## Layout

Full-bleed, без max-width. Каждая секция занимает свой экран (100vh, на телефоне по содержимому). 3D-кресло живёт в одном фиксированном слое под всем контентом и перемещается между позициями:

| Секция | Позиция кресла | Обивка |
|--------|----------------|--------|
| Интро (hero) | справа, 3/4 | букле |
| Идея (reveal) | по центру, разворот в другую сторону | бархат |
| Обивка (интерактив) | по центру | выбор посетителя (по умолчанию кожа) |
| Программа | справа, меньше | лён |
| Запись | по центру, почти фронтально, мелко | букле |
| Автор, формула, кейсы, видео, тарифы, контакты | скрыто сплошным фоном | — |

Reveal-секции следуют сетке ORYZO «текст / объект / текст»: заголовок 41px слева, объект в центре, текст 32px справа, всё выровнено по левому краю. На телефоне кресло поднимается в верхнюю часть экрана, а текст опускается вниз.

## Motion
- Положение кресла плавно интерполируется по прокрутке (smoothstep между центрами секций), плюс медленное «дыхание» по оси Y.
- Смена обивки: оборот на 360° за 0,9 с, ткань меняется на середине, строка промпта перепечатывается.
- `prefers-reduced-motion`: нет оборотов и дыхания, материал меняется сразу.

## Do's and Don'ts

### Do
- Держать один объект, кресло, на всём сайте. Варьируется обивка, а не форма.
- Подавать ИИ как инструмент дизайнера: в текстах «вы задаёте форму, ИИ перебирает варианты».
- Оставлять Ember только голосу ИИ и кредитам.
- Разделять секции 1px пунктиром Cork.

### Don't
- Никаких роботов, неона, «нейро»-градиентов и фиолетового: эстетика интерьерная, тёплая.
- Никаких теней на карточках и кнопках: глубину дают 3D-объект и ступень Walnut → Bark.
- Не центрировать основной текст.
- Не ставить больше одной залитой кнопки.
- Не использовать чистые `#fff` и `#000`.
