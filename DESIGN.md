# АННА / ИИ-ИНТЕРЬЕР — Style Reference
> Тёмная мастерская дизайнера. Одна архитектурная форма парит в тёплой темноте, а ИИ на глазах перебирает для неё материалы.

**Theme:** dark
**Продукт:** онлайн-курс «ИИ в дизайне интерьера» от практикующего дизайнера интерьера.
**Основа:** адаптация системы ORYZO (darkroom product editorial) под образовательный продукт для дизайнеров.

## Идея

Сайт строится вокруг одного объекта: **арки**. Это самый узнаваемый мотив современного интерьера: дверной проём, ниша, зеркало, окно. Арка показана как музейный экспонат: 3D-форма на постаменте, тёплый контровой свет справа сверху, вокруг пустота.

Главная метафора курса — **«Одна форма. Сотня вариантов.»** Форму задаёт дизайнер, а нейросеть мгновенно примеряет к ней материалы, свет и настроение. Поэтому объект на сайте не статичен:
- при прокрутке он поворачивается и переезжает между секциями (как подставка ORYZO, которая разворачивается от вида сверху к 3/4);
- при смене секции «перегенерируется»: делает оборот, и на нём появляется новый материал (штукатурка → травертин → орех → терракота);
- в интерактивной секции посетитель сам выбирает материал и видит строку промпта, которую «отправил» ИИ.

Голос ИИ на сайте — **строка промпта**. Это короткая строка заглавными со слешем в начале: `/МАТЕРИАЛ: ТРАВЕРТИН · СВЕТ: ЗАКАТ`. Только она и подписи-кредиты окрашены акцентным оранжевым.

## Tokens — Typography

### Inter — единственный шрифт
Замена Halyard Display: у Halyard нет кириллицы, а Inter близок по геометрии и хорошо её поддерживает. Включён `"ss01" on`.

- **Weights:** 400, 500
- **Sizes:** 10, 12, 14, 18, 24, 29, 41, 51+ px
- **Letter spacing:** normal на всех размерах
- **Line height:** 1.0 на дисплейных размерах. В ORYZO 0.9, но у кириллицы есть Й и Ё: при меньшем интервале их надстрочные знаки задевают строку выше. 1.0 — самый плотный интервал без столкновений для display. Заголовкам 41px, где чаще встречаются Й и Ё, нужно 1.06.

### Type Scale

| Role | Size | Weight | Case | Line Height | Token |
|------|------|--------|------|-------------|-------|
| micro / label | 10px | 500 | UPPER | 1.2 | `--text-micro` |
| nav / button / prompt | 12px | 500 | UPPER | 1.2 | `--text-label` |
| subheading | 18px | 500 | UPPER | 1 | `--text-sub` |
| heading-sm | 24px | 500 | UPPER | 1.09 | `--text-h-sm` |
| body | 29px | 400 | Mixed | 1.26 | `--text-body` |
| heading | 41px | 500 | UPPER | 1.06 | `--text-h` |
| display | clamp(51px, 6.4vw, 96px) | 500 | UPPER | 1.0 | `--text-display` |

### Два голоса + один
1. **UPPERCASE 500** — всё по умолчанию: заголовки, навигация, кнопки, подписи.
2. **Mixed case 400, 29px** — единственный разговорный голос: объяснение, зачем это дизайнеру.
3. **Голос ИИ** — строка промпта: 12px, UPPER, 500, цвет Ember, всегда начинается с `/`. Появляется посимвольно, как будто печатается.

## Components

### Fixed Top Navigation
Слева вордмарк «АННА» (14px, 500, UPPER). Справа четыре пункта: ИНТРО · ИДЕЯ · ПРОГРАММА · ЗАПИСЬ (12px). Активный пункт подчёркнут 1px пунктиром Driftwood. Фон — градиент от Walnut к прозрачному, чтобы прокручиваемый текст не сталкивался с навигацией. На телефоне остаются ИНТРО и ЗАПИСЬ.

### Vertical Side Label
По правому краю повёрнутый на 90° текст «ИИ-ИНТЕРЬЕР — ПОТОК 01», 10px. Работает как серийный номер экспоната.

### Hero Lockup
Над заголовком tagline 12px: «ОНЛАЙН-КУРС ДЛЯ ДИЗАЙНЕРОВ ИНТЕРЬЕРА». Заголовок display: «ОДНА ФОРМА. / СОТНЯ / ВАРИАНТОВ.» Он прижат к верхнему левому углу, арка стоит справа.

### Hero Info Card (низ слева)
12px радиус, фон `rgba(255,237,215,.05)`, 1px Cork. Внутри заголовок UPPER 12px «АВТОРСКИЙ КУРС АННЫ — ДИЗАЙНЕРА ИНТЕРЬЕРА С 12-ЛЕТНЕЙ ПРАКТИКОЙ.», пунктирный разделитель и три цифры (лет / проектов / учеников).

### Lesson Preview Card (низ справа)
Аналог video thumbnail из ORYZO: маленькая карточка 12px с мини-вордмарком, круглой кнопкой ▶ с кремовой обводкой и подписью «ПРЕВЬЮ УРОКА · 02:14».

### Prompt Line
`/МАТЕРИАЛ: ТРАВЕРТИН · СВЕТ: ЗАКАТ`, Ember, 12px UPPER. Стоит под объектом в каждой reveal-секции и печатается при смене материала.

### Material Chips
Ряд ghost-кнопок 22.5px: ШТУКАТУРКА · ТРАВЕРТИН · ОРЕХ · ТЕРРАКОТА. У активной кремовая заливка и тёмный текст. Нажатие запускает «перегенерацию» арки.

### Program Rows
Список, а не сетка карточек (никаких карточек в карточках): каждая строка отделена пунктиром Cork. Внутри номер (Ember, 12px), название модуля 24px UPPER и описание 18px mixed. При hover строка заливается Bark.

### Input (Underline Only)
Только нижняя граница 1px Cream, радиус 0, внутри справа текстовая кнопка «ОТПРАВИТЬ →».

### Filled Pill — один на всю страницу
«ЗАПИСАТЬСЯ НА ПОТОК»: Bark, 36px, 14px × 24px. Больше залитых кнопок на сайте нет.

## Layout

Full-bleed, без max-width. Каждая секция занимает свой экран (100vh, на телефоне по содержимому). 3D-арка живёт в одном фиксированном слое под всем контентом и перемещается между позициями:

| Секция | Позиция арки | Материал |
|--------|--------------|----------|
| Интро (hero) | справа, 3/4 | штукатурка |
| Идея (reveal) | по центру, разворот в другую сторону | травертин |
| Материалы (интерактив) | по центру | выбор посетителя (по умолчанию орех) |
| Программа | справа, меньше | терракота |
| Запись | по центру, фронтально, мелко | штукатурка |

Reveal-секции следуют сетке ORYZO «текст / объект / текст»: заголовок 41px слева, объект в центре, текст 29px справа, всё выровнено по левому краю. На телефоне арка поднимается в верхнюю часть экрана, а текст опускается вниз.

## Motion
- Положение арки плавно интерполируется по прокрутке (smoothstep между центрами секций), плюс медленное «дыхание» по оси Y.
- Смена материала: оборот на 360° за 0,9 с, текстура меняется на середине, строка промпта перепечатывается.
- `prefers-reduced-motion`: нет оборотов и дыхания, материал меняется сразу.

## Do's and Don'ts

### Do
- Держать одну форму, арку, на всём сайте. Варьируется материал, а не объект.
- Подавать ИИ как инструмент дизайнера: в текстах «вы задаёте форму, ИИ перебирает варианты».
- Оставлять Ember только голосу ИИ и кредитам.
- Разделять секции 1px пунктиром Cork.

### Don't
- Никаких роботов, неона, «нейро»-градиентов и фиолетового: эстетика интерьерная, тёплая.
- Никаких теней на карточках и кнопках: глубину дают 3D-объект и ступень Walnut → Bark.
- Не центрировать основной текст.
- Не ставить больше одной залитой кнопки.
- Не использовать чистые `#fff` и `#000`.
